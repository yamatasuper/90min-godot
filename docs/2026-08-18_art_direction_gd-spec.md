## 1. Саммари
Единый визуальный мир Прибрежья: **живопись Disco Elysium** (масло, охра, teal, усталые взрослые лица) внутри 3D-диорамы. Карты города/стадиона остаются графическими схемами. Сюжет тяжёлый — картинка не помойка. Скромный стадион и скромная команда **живые и ухоженные**. Prefab’ы персонажей и локаций — `Assets/Resources/Prefabs/`.

## 2. AI contract (читать перед генерацией)

Ты — художник игры «90 минут». Каждый кадр — состояние Бардина, не спорт-постер.

**Сначала:** этот файл + паспорт героя из сюжетной библии + style prefix + эталонные карты.  
**Потом:** один `art_id` за раз. Не смешивай нескольких героев в одном промпте, если карточка не просит групповой кадр.

### Обязательный выход
1. `art_id` + тип (`portrait` / `location` / `key_art` / `ui` / `transition` / `map`)
2. RU brief (кто, где, эмоция, что в кадре, что за кадром)
3. English prompt
4. negative prompt
5. камера / свет / палитра
6. must-have детали (3–7)
7. must-not (клише)
8. заметка для human pass (где ИИ обычно врёт)

### Запрещено
- огромные moe/shonen глаза, чиби, «слишком анимешное» лицо
- фотореализм, героический FIFA-постер, солнечный сток, киберпанк-неон
- grimdark, ink-splatter, грязь на форме «потому что скромный клуб», разрушенная раздевалка, лужи мазута, облезлый ад
- читаемый выдуманный текст кроме канона (`Бардин 8`, `Бардин — легенда`, граффити из библии)
- лишние пальцы, watermark, plastic skin, «AI glow»
- делать Бардина молодым фитнес-моделью
- западноевропейский премьерлиговый стадион вместо «Торпедо»

### После генерации
Не считать кадр готовым. Чеклист human pass — §11 и `art_pipeline`.

## 3. Стиль-лок (этот файл главнее `art_pipeline`)

Пайплайн 12 августа (human pass, Ken Burns, запрет as-is, cut order) — техника. **Палитра, персонажи, локации, обложка, prompt prefix — отсюда.** Если старый prefix спорит с новым — новый.

**Стиль:** Disco Elysium / ZA/UM painterly: масляный мазок, приглушённая охра и teal, чуть «некрасивые» взрослые лица, изометрия камеры. Не FIFA, не фото, не чиби, не anime-глаза, не «грязный пост-апок».

**Эталоны (держать рядом при генерации):**
- портреты и full-body: `Assets/Resources/Art/Portraits/`, `Art/Characters/sprite_*.png` — живопись DE
- карта города и схема стадиона — только для географии, не для стиля лиц
- цвет формы: горчично-охристая полоса на тёмной кит
- лица: взрослые реалистичные, усталость, без блёсток

**Не эталоны:** STALKER / «всё в ржавчине»; shonen-портреты; photoreal FIFA.

**Палитра:**
- серый — линия, бетон, трибуны, небо (светлое, не уголь)
- горчичный жёлтый — форма, закрытый запад, мелкие акценты (не заливка)
- стальная синева — река
- кожа — живая, без грязных разводов и «грязи бедности»
- редкий золотой просвет на горизонте = прощание, не хеппи-постер

**Свет:** ясный дневной или ровный рабочий. Раздевалка — чистая практичная лампа, не подвал. Поле — светло. Больница — стерильный белый. Ресторан — тёплые свечи без копоти. Завод — цех, который работает, не свалка.

**Обработка:** чистая линия, умеренный штрих. Без плёночного зерна «ужаса», без виньетки-гроба. Флэшбеки — чуть мягче фокус, не сепия-кладбище.

### Правило скромности
Скромный город ≠ руины. Скромная команда ≠ грязная форма. Скромная раздевалка ≠ граффити, плесень и сломанные шкафчики.  
«Торпедо» — действующий провинциальный стадион: газон стригут, шкафчики стоят ровно, кит чистый. Запад закрыт на реконструкцию (леса, жёлтая зона) — это ремонт, не катастрофа.

### Stable prompt prefix
Не менять mid-project без записи в историю.

```
Disco Elysium oil-painting video game art, painterly brushstrokes, muted ochre and teal palette, realistic tired adult faces, modest tidy provincial football world, lived-in not filthy, no watermark, no extra limbs, no unreadable random text, not photoreal, not FIFA, not anime, not chibi, not grimdark sludge
```

Для матч-панелей добавь в конец: `comic panel framing, clear focal action, same world and palette, not manga speedlines overload`.

Для портретов добавь: `realistic adult face, slightly stylized eyes, not huge sparkle moe/shonen eyes`.

### Negative prompt (всегда)

```
chibi, huge sparkle moe eyes, shonen face, photoreal, FIFA, eFootball, Unreal Engine sports screenshot, neon cyberpunk, grimdark, muddy kit, filthy locker room, rust apocalypse, ink splatters, grime on skin, ruined abandoned stadium, stock sunset couple, plastic skin, extra fingers, extra legs, watermark, logo, unreadable text, beauty filter, stadium fireworks, packed Premier League crowd, heroic low-angle poster
```

Must-have: обрыв и стальная река за воротами, мачты, закрытый запад как ремонт, скромный ухоженный газон, светлый день.

## 6. Ключевые арты (приоритет)

Генерировать в этом порядке, если времени мало: 1 → 3 → 2 → 8 → 9, остальное позже. Вариации матч-панелей режутся первыми (`art_pipeline`).

### `art_key_cover` — обложка
Бардин на «Торпедо» **спиной**. Смотрит на реку за воротами. Светлое небо, золотистый просвет. Скромная чистая форма. Запад: баннер «Бардин — легенда». В руках старый мяч. Прощание, не постер победы.
Композиция: силуэт в центре, река сзади, стадион обрамляет.

### `art_key_locker` — раздевалка
Бардин бинтует ногу. Глок смотрит на него. Пень в углу в телефон. Сокол в наушниках. Тёплый ровный свет. Усталость и ожидание. Помещение скромное и чистое.

### `art_key_face` — лицо на поле
Крупно. Смотрит вверх. Морщины, усталость, лёгкая улыбка принятия. Стадион размыт. Реалистичное взрослое лицо.

### `art_key_river` — река
С трибуны / от ворот. Стальная вода, светлое небо. Ворота на переднем плане. Бардин спиной.

### `art_key_apartment` — квартира
Сидит на полу среди коробок. Свет из окна. В руках фото с женой. Печаль без горечи-плаката.

### `art_key_factory` — завод
14-летний бьёт мячом в железные ворота. Длинные тени. Отец — силуэт без лица. Цех, не руина.

### `art_key_fall` — падение
Колено не держит. Живая трава. Смотрит в небо. Тень Глока или тренера. Боль на лице, не splatter.

### `art_key_whistle` — после свистка
Один на поле. Светлое небо. Снятые бутсы в руках.

### `art_key_epilogue` — эпилог
Новая дешёвая квартира. Мяч на полу. Смотрит в окно на ту же реку. Спокойное лицо. Скромно, не убого.

## 7. UI и переходы

| элемент | правило |
|---|---|
| цвета UI | светло-серый, стальной синий, горчичный жёлтый акцент |
| шрифт | крупный, ясный; не футуризм |
| кнопки выборов | три круга: синий / жёлтый / серый |
| фон меню | стадион + река в стиле схемы |
| вход в прошлое | чёрный → кадр локации → резкость; мягкий фокус, без кладбищенской виньетки |
| триггер-воспоминание в матче | глубокий фокус, стадион глуше, одно изображение прошлого |

Не рисовать в UI случайные цифры статов. Статы скрыты (`soft_stats` / сюжетная библия).

## 8. Техтребования кадра

| параметр | значение |
|---|---|
| `art_resolution` | 1920×1080 или 3840×2160 |
| `art_format` | png или psd со слоями |
| `style_processing` | seinen линия, лёгкий штрих, без grimdark-зерна |
| `ken_burns` | медленный pan/zoom на still |
| `page_flip` | для матч-комикса |
| `ai_as_is_allowed` | false |

Имена файлов как в пайплайне: `art/<type>/<id>_v##.png`. Игровые копии: `Assets/Resources/Art/`.

## 9. Рецепты промптов по типу

### Портрет
```
{prefix}, waist-up portrait of {anchor}, realistic adult face slightly stylized eyes, locker-room practical lamp OR overcast stadium daylight, emotional interiority, shallow depth, mustard-yellow kit accents
```

### Локация без героя
```
{prefix}, establishing shot of {location anchors}, empty of crowds or sparsely populated, no hero, architecture as mood, tidy modest not ruined
```

### Ключевой кадр с героем
```
{prefix}, {composition from card}, Aleksei Bardin {pose}, {palette}, story still not promotional key-art gloss
```

### Флэшбек
```
{prefix}, slightly softer focus, {year} details, not a time-travel VFX plate, not sepia graveyard
```

### Карта / схема
Держать линию эталонных JPG. Грейскейл + стальная река + жёлтый акцент закрытого запада. Без каши-текста на баннерах.

## 11. Human pass checklist
- [ ] Кроп под бабблы/UI
- [ ] Палитра библии, не дефолт модели
- [ ] Лицо = portrait sheet, взрослые пропорции, не огромные аниме-глаза
- [ ] Нет артефактов, водяных знаков, лишних пальцев, каши-текста
- [ ] Трибуны не «Камп Ноу» и не руина
- [ ] Форма и раздевалка чистые
- [ ] Бардин не выглядит на 24
- [ ] Кадр не мрачнее карты/схемы-эталона
- [ ] Линия стыкуется с соседними кадрами
- [ ] Размер/mips, читаемость на Low

## 12. Acceptance
1. Prefix и negative стабильны.
2. Обложка и лицо героя узнаваемы; лицо реалистичнее shonen-рефа.
3. Западная трибуна закрыта как реконструкция, река за воротами есть.
4. ИИ-кадр без pass не в билде.
5. Матч не выглядит как футсимулятор.
6. Скромность читается как провинция, не как грязь.
