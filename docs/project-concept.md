# 90 минут — концепт проекта

Канон контента (сюжет, каст, статы, арт, музыка): `docs/ai-content-index.md` и библии `docs/2026-08-18_*`. Они **важнее** вертикального среза и ТЗ от 2026-08-12.

## Рабочее название
**90 минут**

## Жанр и формат сессий
- Жанр: реалистичная психологическая драма с интерактивным повествованием; narrative RPG / визуальная новелла в футбольной рамке
- Мир: вымышленный пост-советский город **Прибрежье**, стадион **«Торпедо»**
- Герой: **Алексей Бардин**, 34, опорный полузащитник, бывший капитан, контракт на исходе
- Темп: спокойный, меланхоличный, тревожный, телесный
- Сессия: вечер; полный матч + перерыв с прошлым — длиннее среза (срез 15–25 мин остаётся тестом пайплайна, не каноном истории)
- Платформы: PC (старт), мобильные — по возможности
- Дистрибуция: **premium** (разовая покупка), без IAP / DLC / подписки

## ЦА и ключевое обещание
- **Обещание:** 90 минут последнего матча = вся жизнь. Без футбола герой не знает, кто он.
- **ЦА:** люди в неопределённости будущего; также те, кого цепляет футбол без FIFA-фантези.
- **Эмоция после сессии:** прощание, пустота, редкая надежда; не «победил — молодец».
- **Почему не аналоги:** проверки статов внутри матча, скрытые состояния, сегменты прошлого на перерыве, семьи концовок A–Ж.

## Core fantasy
Ты — Бардин на своём последнем матче. Хребет — **поле и раздевалка в настоящем** (триггеры, микропаузы, выборы). Исследование локаций — **3D от третьего лица**; матч и диалоги остаются иллюстрациями. Прошлое — полноценные локации на перерыве. Это не футбольный симулятор.

## Core loop
1. Сцена настоящего (раздевалка / бит матча / микропауза).
2. Выбор: атмосфера или проверка статов (ФВ, ХЛ, СК, ИН + скрытые).
3. Короткая вспышка памяти внутри триггера.
4. На перерыве: разговор / осмотр / **сегмент прошлого 10–15 мин**.
5. Возврат во второй тайм с изменёнными статами → концовка A–Ж → эпилог.

Единица: **триггер матча** и отдельно **сегмент прошлого**.

## Структура матча (ритуал, не симуляция)
1. Пролог: раздевалка, 10 минут до выхода
2. Первый тайм: фазы с триггерами и микропаузами
3. Перерыв: команда + исследование прошлого
4. Второй тайм
5. Концовка на поле / вне его + эпилог (квартира, письмо, река)

**Показ:** иллюстрации, Ken Burns, текст, звук толпы. Без тяжёлой анимации геймплея на поле.

## Прогрессия
- **Долгосрочная цель:** понять, кто ты без мяча и без денег.
- **Короткий горизонт:** триггер + выбор.
- **Средний:** тайм / перерыв.
- **Длинный:** семьи концовок A–Ж и эпилог по ИН/НАД.
- **Статы (канон):** выносливость, хладнокровие, связь с командой, интроспекция; скрытые: агрессия, боль в коленях, усталость, ностальгия, тревога, сожаление, надежда. Не DnD-билд, но проверки реальны.
- **Концовки:** семьи A–Ж (падение, победа, ничья, удаление, твой гол, крик с трибуны, дождь) с ветками по статам — не три плаката good/mid/bad.
- **Колено:** при боли ≥ 10 на 78-й — замена / концовка A. Сейв до травмы обязателен.

## Выборы и вариативность
- Проверки: сумма текущих статов ≥ сложности.
- Атмосферные выборы не двигают статы.
- Голы и пропуски висят на конкретных триггерах, счёт — состояние, не фиксированный 2:2.
- Ломание клише: победа может быть пустой; падение может быть принятием.

## Границы MVP
**Обязательно:**
- сюжет и персонажи;
- `narrative_core`, `choice_score_bridge`, `match_frame_ui`, `match_presentation`, `world_exploration`, `characters_dialogue`, `endings_system`, `cliche_twist_content`;
- 2 тайма (упрощать нельзя — это матч);
- сейв в любой момент + загрузка до травмы;
- атмосфера и сильная история важнее полировки.

**Можно упростить на старте:**
- число локаций;
- всё на заглушках → сначала база и сюжет, потом полировка арта/звука/адаптации.

**P1/P2:**
- озвучка (скорее всего только автор и максимум партнёр; например комментатор);
- расширенный набор локаций/персонажей;
- полировка «незаметного» ИИ-арта и музыки;
- мобильная адаптация экранов;
- низкие системные требования и стабильность как явные цели качества.

## Ключевые риски
1. **Показ матча** при ограниченных навыках анимации — пайплайн иллюстрация / Ken Burns / UI.
2. **Объём:** полный тайм триггеров + 7 сегментов прошлого слишком велик для соло; в одном проходе резать число сегментов на перерыве, не канон мира.
3. **Текст** без затянутости: жать микропаузы, не факты биографии.
4. **Концовка A (колено)** не должна ощущаться читерским геймовером: сейв до травмы обязателен.

## Производство
- Соло-проект, горизонт до играбельного билда — месяцы.
- Порядок: заглушки → база и сюжет → полировка.
- Арт и музыка могут создаваться с помощью ИИ при условии, что итог не выглядит «очевидно ИИ».
